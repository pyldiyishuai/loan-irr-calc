# 分期真实利率计算器

> 销售说「月费率 0.75%，年化才 9%」。
> 真实年化是 **17.48%**。差了一倍。

纯静态站点，双击 `index.html` 就能跑。

---

## 一、为什么差这么多

手续费按**初始本金**收，但你的欠款在逐月减少。

借 12,000 元 / 12 期 / 月费率 0.75%：

| 期数 | 剩余本金 | 手续费 | 实际费率 |
|---|---|---|---|
| 1 | 12,000 | 90 | 0.75% |
| 6 | 7,000 | 90 | 1.29% |
| 12 | 1,000 | 90 | **9.00%** |

最后一期你只欠 1/12 的本金，却还在付全额手续费。

**平均占用资金只有约 6,500 元，却为 12,000 元付了全款费用。**

---

## 二、真实年化怎么算

把所有现金流列出来，求让净现值为 0 的贴现率：

```
12000 = 1090 × [1 − (1 + r)^−12] / r
```

解得月利率 `r ≈ 1.35%`，年化 `(1 + r)^12 − 1 = 17.48%`。

本工具用**二分法**求解，精度 1e-9，不是估算。

### 名义 vs 真实

| 口径 | 算法 | 结果 |
|---|---|---|
| 名义年化 | 月费率 × 12 | 9.00% |
| 真实年化 | IRR（复利年化） | **17.48%** |
| 倍数 | — | 1.94 倍 |

## 五、改代码前必看

### 1. IRR 用二分法，不用牛顿法

```js
// NPV 关于 rate 单调递减 → 二分法一定收敛
var lo = -0.9999, hi = 10;
// 牛顿法在接近 −100% 时导数趋 0，会发散
```

### 2. 月利率 → 年化是复利

```js
annual = Math.pow(1 + monthly, 12) - 1   // ✅
annual = monthly * 12                     // ❌ 这是名义年化
```

### 3. 手续费不随本金递减

这是本工具存在的全部理由。如果写成「按剩余本金计息」，
算出来就是普通贷款，没有意义了。

### 4. 产品预设只是参考值

`data/loan-presets.js` 里的费率是公开信息整理的典型值。
不同人、不同期数、不同活动，费率都不一样，要提示用户以合同为准。

## 八、免责

本工具按「等额本息 + 固定手续费」的标准分期形态计算 IRR。
等额本金、先息后本、随借随还等产品结构不同，结果会有差异。
实际利率以借款合同与机构披露的年化利率为准。
年化超过 24% 请谨慎借贷。
