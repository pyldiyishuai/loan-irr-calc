## 二、判断值不值得做

1. 有「算」的动作 ✓
2. 答案反直觉（9% vs 17.5%）✓
3. 全年稳定搜索 ✓（比个税更好）
4. 高 CPC 广告主 ✓（银行、消金）

**这个需求比年终奖个税更稳**，因为不受季节影响。

---

## 三、冷启动

### 1. 先做换算对照表

比首页更容易排上去，而且用户看完表自然会想「算算我自己的」。

### 2. 知乎回答「XX 分期划算吗」

这类问题下给一个真实计算过程 + 工具链接，存活率高。
重点是要**给出完整算式**，不能只说「大概 17%」。

### 3. 蹭监管政策

LPR 一调，「民间借贷利率上限」的搜索量就涨。
提前准备好模板，当天发布。

### 4. 不要做的事

- 不要做「帮你找最低利率贷款」的导流（容易变成助贷，合规风险高）
- 不要为了流量夸大数字（比如把 17.48% 说成 20%），会失去专业用户信任

---

## 四、文案红线

1. **必须区分名义年化与真实年化**，不能混用「年化」一个词
2. **产品预设费率要标注「典型值，以合同为准」**
3. **不要说「这是高利贷」** —— 只给数字和参照线，让用户自己判断
4. **LPR 相关数字要标日期**，4 倍上限会变
5. **不承诺「一定更划算」**，只做对比
